# Parakeet landing page

Responsive, original landing page inspired by Parakeet AI. HTML, CSS, JavaScript, and Vite. The interactive demo uses scripted answers; live AI, payments, authentication, and audio recording are not implemented.

## Development

`npm ci` then `npm run dev -- --host 0.0.0.0`

## Production

`npm run build` then `npm run preview -- --host 0.0.0.0`

## Vercel

Import Deepesh-7879/parakeetAI, select Vite, build with `npm run build`, output `dist`. No environment variables required. Domain and account access must be configured in Vercel.
